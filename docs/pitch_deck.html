The WRRF Formulation

Score(d) = [0.5 / (60 + r_vec(d))] + [0.5 / (60 + r_graph(d))]

  • r_vec(d): Rank order from dense cosine vector embedding retrieval.
  • r_graph(d): Rank order from topological BFS graph distance and centrality.
  • k = 60 constant: Prevents individual high-ranking outliers from dominating.
